# 来电速查 — 需求文档

## 1. 背景与目标

广告和骚扰电话较多，陌生来电缺少判断依据。本应用在来电、去电和通话过程中，通过悬浮窗展示该号码在本机的历史通话统计，帮助用户快速判断是否接听。

所有统计均来自本机 `CallLog.Calls`，不上传任何号码或通话数据。

## 2. 目标用户

使用 Android 手机、经常收到陌生来电，希望在不改变系统拨号应用的前提下快速识别来电价值的用户。

## 3. 平台范围

- v1 仅支持 Android（`minSdk 26`，`compileSdk/targetSdk 36`）。
- 不支持 iOS 和 HarmonyOS：这两个平台不向第三方应用开放“来电时读取号码 + 通话记录 + 叠加浮层”的组合能力。
- 分发渠道：国内应用市场 + GitHub 直接分发 APK。

## 4. v1 功能范围

### 4.1 权限

所有敏感权限必须在运行时由用户主动授权，`AndroidManifest.xml` 声明仅为必要条件。

| 权限 | 类型 | 用途 |
| --- | --- | --- |
| `READ_CALL_LOG` | 运行时 | 读取本机通话记录 |
| `READ_PHONE_STATE` | 运行时 | 监听通话状态，并获取来电/去电号码 |
| `SYSTEM_ALERT_WINDOW` | 特殊授权 | 在来电、去电、通话中展示浮层 |
| `POST_NOTIFICATIONS` | 运行时（Android 13+） | 展示监听前台服务通知 |
| 忽略电池优化 | 特殊授权（可选） | 降低后台监听被系统回收的概率 |

应用不得声明 `INTERNET` 权限，从系统层面保证数据无法上传。

### 4.2 监听

- 用户手动开启监听后，以前台服务常驻，通知栏展示运行状态。
- 监听系统 `PHONE_STATE` 广播，使用 `READ_CALL_LOG` 提供的号码识别来电与去电。
- 开机后，若用户已开启监听且权限完整，自动恢复监听。
- 提供小米/HyperOS 自启动与省电策略设置入口及说明。

### 4.3 浮层

| 场景 | 行为 |
| --- | --- |
| 来电响铃 | 展示号码统计浮层 |
| 去电拨号 | 展示号码统计浮层（可配置关闭） |
| 通话中 | 保留浮层，数秒后自动收起为一行；可点击展开、可拖动 |
| 通话结束 | 浮层自动消失 |
| 未知/隐藏号码 | 不展示浮层 |
| 权限不足 | 不展示浮层，应用内提示 |

浮层只读展示，不提供接听、挂断、拦截、静音等操作。

### 4.4 展示内容

- 号码。
- 是否首次来电：以**全量通话记录**判断，统计周期不影响该判定。
- 最近窗口内的历史来电：总次数、已接听次数、未接次数。
- 最近窗口内的历史去电：总次数、成功接通次数。
- 接听与去电的累计通话时长。
- 最近一次接听的时间与通话时长。
- 最近一次去电的时间与通话时长。
- 重复来电提示：配置窗口内（默认 10 分钟）第 N 次来电高亮。

### 4.5 设置

| 设置项 | 默认值 | 范围 |
| --- | --- | --- |
| 重复来电窗口 | 10 分钟 | 1–60 分钟 |
| 统计周期 | 6 个月 | 1–24 个月 |
| 号码归一化匹配 | 开启 | 开/关 |
| 去电时展示浮层 | 开启 | 开/关 |

号码匹配规则：

- 归一化模式（默认）：去除空格、横线等非数字字符；`0086` 前缀去除；`86` + 10/11 位号码时去除国家码；再比较完整号码。
- 严格模式：仅去除非数字字符，不做国家码归一化。
- 不使用“后 N 位”模糊匹配。

## 5. 统计口径

数据来源仅 `CallLog.Calls`：

- 历史来电 = `INCOMING_TYPE` + `MISSED_TYPE`。
- 已接听 = `INCOMING_TYPE` 且 `duration > 0`。
- 未接 = `MISSED_TYPE`。
- 历史去电 = `OUTGOING_TYPE`。
- 去电接通 = `OUTGOING_TYPE` 且 `duration > 0`。
- `REJECTED_TYPE`、`BLOCKED_TYPE`、`VOICEMAIL_TYPE` 不参与 v1 统计。
- 首次来电 = 全量记录中不存在任何一种来电记录。
- 所有次数与时长统计仅覆盖配置的统计周期。
- 重复来电次数 = 窗口内已有来电/未接次数 + 当前来电。

## 6. 非目标

- 不做号码拦截、静音、自动挂断。
- 不做云端号码库、骚扰标记、众包数据。
- 不读取或展示联系人名称。
- 不区分双卡/SIM 卡。
- 不做通话录音、备份、导出。
- v1 不做 CI、release 签名与上架合规适配。

## 7. 验收标准

1. Android 8.0–16 可安装；`assembleDebug`、`lintDebug`、单元测试通过。
2. 应用无 `INTERNET` 权限。
3. 权限清单中的运行时权限均在应用内弹窗请求，拒绝后显示未授权状态且不会崩溃。
4. 来电响铃约 1 秒内展示浮层；去电拨号同样展示；通话中浮层保留并自动收起；通话结束消失。
5. 浮层内容与统计口径一致；首次来电判定使用全量记录。
6. 重复来电窗口、统计周期、号码匹配模式、去电展示开关均可配置并即时生效。
7. 真机（Redmi K80 / HyperOS）验证：锁屏来电可见、悬浮窗可拖动、不会阻塞系统来电界面操作。

## 8. 风险与限制

- `READ_CALL_LOG` 在 Google Play 属于受限权限，无法通过常规审核；本项目面向国内渠道与 GitHub 侧载。
- 非默认拨号器无法获取完整的通话控制能力；v1 依赖 `PHONE_STATE` 广播附带号码，需在目标机型验证。
- 锁屏浮层、后台保活、国产 ROM 自启动策略存在机型差异，需要真机验证与用户手动设置。
- 系统清理通话记录后，历史统计会相应减少。
